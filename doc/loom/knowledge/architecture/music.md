# Music

> scorekit (samples, score, mix, qc, render) and Lyria: gen, beat grid, finish

## scorekit (music/)

One uv project (package name `scorekit`; Python >= 3.12; numpy, scipy, soundfile, soxr, pyloudnorm, matplotlib, `pedalboard`). `uv run render.py [--out out] [--seed 7] [--qc] [--excerpt A B]` composes the cue with the project's `<project>/music/arrangement.py` (`compose(seed)` returns a `scorekit.score.Score`) and writes `music/out/soundtrack.wav`, `music/out/stems/*.wav` (48 kHz, 24-bit, sample-aligned) and `manifest.json` (tempo, bar grid, section starts, `sample_libraries`: the libraries the score used, which `edit/editkit/credit_data.music_samples()` reads to credit Salamander only when used). `--excerpt` writes a slice for the audio judge. `uv run render.py --selftest` renders eight bars of synthesized C major, no samples needed. The edit reads `music/out/soundtrack.wav` and `music/out/stems/` (a finished Lyria take has no stems); a video without music has neither.

Modules in `music/scorekit/`:
- `library.py`: indexes the sample libraries (Salamander Grand Piano as sfz, VSCO-2 CE folders) into zones (sample, MIDI pitch, velocity band, round-robin index). `setup.sh` downloads, only when `project.json` `music` is `score` (the default), VSCO-2 CE, and Salamander only when `piano` is `salamander`, into `music/samples/` (not installed, not committed); `music/CREDITS.md` records the licences.
- `sampler.py`: repitch, envelope, sustain extension, stereo placement. `instruments.py`: `STEMS` (piano, strings, mallets, bass, percussion, synth, winds), `piano_library()` (`project.json` `piano` through `tools/project_settings`) and the `registry()` of instruments; `piano` plays VSCO's Upright Nr1 unless `piano_library()` is `salamander`.
- `score.py`: `Score`, per-instrument timing jitter and lag. `timing.py`: `Grid` (the bar grid) and `narration_windows()` read from `narration/timeline.json`, so cues land on the narration's clock.
- `theory.py` (chords and voicings), `parts.py` (ostinati, pulses, bass, melody, strings), `drums.py`, `percussion.py` (VSCO one-shots plus synthesized pieces), `synth.py` (pluck, sub bass, kick, clap, riser).
- `mix.py`: synthetic room and hall impulse responses, stem buses and loudness through `pedalboard`, with mid dips that keep 1-4 kHz open for the narrator. `qc.py`: spectrograms, loudness curves, onset density, tempo estimate, centroid and click hunting, for review without ears.

## Lyria (music/lyria.py)

`project.json` `music` picks the source: `score` (scorekit, the default), `lyria-3.5`, `lyria-3-clip-preview` or `none`. `music/lyria.py` (in the scorekit uv project, `google-genai` dependency) has three entry points:
- `gen [--takes N] [--prompt FILE] [--model ID] [--sections]`: one `client.interactions.create` per take (model from `project.json` unless `--model`; `lyria-3.5` gets `response_format={"type": "audio"}` for WAV, the clip model returns MP3). `audio_bytes()` accepts base64 text or raw MP3/WAV bytes. Writes `music/out/lyria/take-NN.{wav,mp3,json}`, numbered after the highest existing take, files opened with `xb` so nothing is overwritten. A failed call is retried once; an HTTP 400 (a prompt naming an artist or band) never. Every attempt logs a `usage.jsonl` line (script `lyria`) and a `music` metrics line; the success line is written before decoding, so a decode failure still records the billed call. `--sections` appends `narration/timeline.json` scenes as `[m:ss - m:ss] key` lines.
- `finish <take> [--end] [--fade 3] [--start]`: `scorekit/finish.py` resamples to 48 kHz, measures the grid with `scorekit/beatgrid.py`, cuts at `--end` (default: the timeline total) snapped to the nearest downbeat (`--start` snapped too, 0 kept), fades and masters with `mix.master()` (-16 LUFS, -1 dBTP). Writes `music/out/soundtrack.wav`, removes `music/out/stems/`, writes `music/manifest.json` with scorekit's keys (`bpm`, `bar_0_at`, `downbeats`, `beats`, `tempo_map`, `speech_windows`, `sections: []`, `stems: {}`, `sample_libraries: []`) plus `source`, and replaces a `## Lyria soundtrack` section in `music/CREDITS.md`. `edit/editkit/credit_data.music_samples()` skips the section headed `Lyria soundtrack` (`credit_data.LYRIA_RECORD`) and credits every other section, so the record never reaches the credits.
- `--selftest`: a synthesized 117 BPM click track encoded as MP3, through `audio_bytes()`, `store_audio()` and `finish` into `music/out/selftest-lyria/`; fails unless tempo, start phase, snapped length, loudness and true peak match. `music/tests/test_lyria.py` (pytest dev dependency) covers retries, refusals, usage lines, numbering and formats with a fake client.

`beatgrid.measure()`: `qc.tempo_estimate()` for a first period, a comb over `qc.onset_strength()` (period +-2.5 %, phase in 5 ms steps), a least-squares line through `qc.onsets()` within 40 ms of each predicted beat, and the downbeat as the beat phase (4/4 assumed) with the most full-band plus low-band (< 150 Hz) attack. `LAG = 0.045`: the log-spectral flux peaks about one 2048-sample window after an attack, measured on click tracks. On the three takes in `~/src/loom-tokens-video/music/out/lyria/` it measured 145.0, 95.0 and 185.0 BPM, and lyria_2's downbeats within about 25 ms of the librosa grid recorded there.
